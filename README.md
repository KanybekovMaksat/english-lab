# AiCo Word Lab — английский через опыты (3D-книга + воронка на открытый урок)

Открытая 3D-книга для детей 7–12 лет: 10 опытов, 60 английских слов. Механика взята у [Every Joule](https://iamtechartist.com/every-joule/), цвета и маскот — из айдентики AiCo. Книга — лид-магнит для бесплатного открытого урока Codify English.

## Как проходит урок

У каждого урока шесть шагов строго по порядку: **Слова → Прогноз → Опыт → Say it → Why? → Штамп**. Активен только текущий шаг.

- **Указатель:** лаймовое кольцо всегда стоит на том, что нажать сейчас.
- **Рука:** показывает жест в уроках 1–2, а позже — после 5 секунд бездействия или неверного нажатия.
- **Подсказка AiCo:** английская фраза голосом и русский перевод под ней. При первой встрече с каждым шагом AiCo один раз объясняет его по-русски голосом Eugene.
- **На телефоне:** сверху опыт в 3D, снизу панель с текущим шагом. Кнопки там не меньше 48 px, текст не меньше 16 px.
- **На компьютере:** разворот книги, неактивные шаги приглушены, внизу — полоска AiCo с главной кнопкой шага.

## Воронка

- **Открыто и закрыто.** Уроки 1–5 бесплатны. Уроки 6–10 открываются после заявки родителя на бесплатный открытый урок.
- **Когда книга зовёт родителя.** После 2-го и 4-го штампа появляется небольшая карточка «Покажи маме или папе» с кнопками «Показать» и «Потом». Это не модальное окно, каждая карточка показывается один раз. Попытка открыть урок 6 показывает ту же страницу как замок. Кнопка «Родителям» и финальный разворот ведут туда же.
- **Что видит родитель.** Результат ребёнка (опыты, слова, верные прогнозы) и 5 опытов открытого урока. Ниже — факты с english.codify.kg: 21–22 ноября, Codify Джал, Тыналиева 127, ведёт Майкл. В форме четыре поля: возраст (7–9 / 10–12), день, имя и телефон +996.
- **Куда уходит заявка.** В `https://leads.codify.kg/forms/landing` — тот же сервис amoCRM, что и у формы сайта (тег english, код источника `wordlab`). **Сервис принимает заявки только с адреса `https://english.codify.kg`.** Поэтому книгу нужно выложить туда, например в `english.codify.kg/lab/`. С любого другого адреса заявка уходит в WhatsApp отдела продаж (+996 500 431 430) готовым сообщением, как делает сам сайт.
- **Аналитика.** События `open`, `lesson_start`, `stamp`, `said_it`, `flap`, `ParentView`, `Lead`, `LeadFallback`, `Contact` и `unlock` уходят в Meta Pixel, GA и dataLayer, если те подключены на странице.
- **Где менять даты открытых уроков:** `FUNNEL.slots` в `src/funnel.js`. Прошедшие даты скрываются сами, вариант «Другой день» есть всегда.
- **Номер телефона** проверяется: 9 цифр после +996, первая цифра 2, 3, 5, 7 или 9.
- **Ссылка-ключ** `?unlock=lab` открывает уроки 6–10 на другом телефоне. Она есть в сообщении WhatsApp и на экране «Заявка принята».
- **Перед запуском:**
  - Выложить `dist/` на english.codify.kg, например в папку `/lab/`.
  - Отправить одну тестовую заявку и проверить, что сделка с кодом `wordlab` появилась в amoCRM.
  - В `index.html` заменить `og:image` на абсолютный адрес (`https://english.codify.kg/lab/og.png`), иначе WhatsApp не покажет превью.
  - Если нужна аналитика — вставить в `index.html` код Meta Pixel или GA. На сайте их сейчас нет.
  - Согласовать с преподавателем программу открытого урока: родителям обещаны именно эти 5 опытов.

## Открытый урок

Папка `trial-lesson/`:

- `run-sheet.html` / `.pdf` — план на 55 минут для преподавателя. В нём 5 опытов (апельсин-фокусник, магнитная рыбалка, радуга из конфет, гонка ракет-шариков, вулкан и видео-отчёт), материалы, английские фразы, «вау» для родителей и сообщение родителю вечером.

## Голос

Все английские фразы озвучены в ElevenLabs заранее: 170 mp3 в `public/voice/`, модель `eleven_multilingual_v2`.

- **Английский голос:** Alice (британский, «educator»).
- **Русские подсказки:** Eugene, утверждённый голос AiCo.
- **Если mp3 нет** (не скачался или нет в манифесте), фразу читает голос браузера.
- **Переозвучка после правки текстов:** `node tools/voice.mjs`. Озвучиваются только изменённые фразы. Ключ берётся из `ELEVENLABS_API_KEY` или из `Максат Бренд/maksat-brand/.env`. Посчитать символы без озвучки: `--dry`.

## Запуск

```bash
npm install
npm run dev      # http://127.0.0.1:4499 (с телефона в той же Wi-Fi: адрес Mac :4499)
npm test         # 10 тестов: контент, порядок шагов, замок 6–10, воронка, каждая фраза озвучена
npm run build    # статический сайт в dist/, base './' — кладётся в любую папку
```

## Устройство

- **Сцена:** Three.js. Книга — `src/book.js`, страницы рисуются на canvas — `src/pages.js` и `src/paint.js`. Чернильный шейдер и свечение — `src/ink.js`.
- **Опыты:** 10 файлов в `src/labs/`. Опыт создаётся при первом открытии своего разворота.
- **Шаги урока:** `src/state.js`. Указатель и камера — `src/main.js`. Панель для телефона и полоска AiCo — `src/ui.js` и `src/ui.css`. Воронка — `src/funnel.js`.
- **Тексты:** уроки, подсказки AiCo и 5 опытов открытого урока — `src/content.js`.
